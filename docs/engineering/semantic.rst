Semantic frontend
=================

Recognition is generated by ANTLR 4.13.1. ``DeckParser.Parse`` never opens include
files, evaluates parameters, executes controls or invokes a simulator.

Three explicit subsequent operations are available:

* ``ResourceResolver.Resolve`` loads permitted UTF-8 resources under budgets and
  returns atomic expanded text plus original-file source segments.
* ``InstanceBinder.Bind`` binds observed X/model references and ordered ports,
  retaining missing, ambiguous, deferred, invalid and unsupported outcomes.
* ``ParameterEvaluator.Evaluate`` and ``ForInstance`` evaluate finite lexical
  parameter profiles with catalog-branded per-instance environments.

Binding is symbolic; hierarchy flattening, ground/global translation, model
parameter lowering and the Rust numerical bridge remain separate work. The
observed corpus profile performs no resource loading or numerical execution.
The matched ngspice profiles are named finite checks, not full SPICE conformance.

Refer to the repository's ``docs/semantic-frontend.md`` for exact supported
operators, numeric suffixes, default/override policies, resource limits, source
mapping and reproducible commands. All new generated outputs on the current
Windows host belong on E:. No native Linux, GPU or production qualification is
implied; the exFAT artifact volume cannot qualify symbolic-link creation.
